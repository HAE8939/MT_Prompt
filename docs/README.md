# Documentation

- `reference/`: original Chinese requirements, data design, API, frontend, compiler, template, skill, and rule-engine documents.
- `assets/`: UI prototype and other visual references.
- `superpowers/specs/`: approved product specifications.
- `superpowers/plans/`: implementation plans.

The files in `reference/` preserve the source material. Current implementation decisions are documented in `superpowers/specs/` and `superpowers/plans/`.
