# PromptVault V1.1-V1.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with verification checkpoints.

**Goal:** Extend the local PromptVault V1 foundation with recoverable backups, scalable library workflows, explainable compilation, and a generic OpenAI-compatible AI Provider.

**Architecture:** Keep SQLite and local filesystem as the source of truth. Add an import/restore service that validates a ZIP manifest before a transaction, expand Prompt/Asset query capabilities without changing existing DTO contracts unnecessarily, keep the compiler pure, and isolate AI calls behind a Provider interface. Secrets remain in Windows Credential Manager.

**Tech Stack:** Fastify, Prisma/SQLite, React/Vite, TanStack Query, Zod, Vitest, Playwright, Node fetch, Windows Credential Manager.
