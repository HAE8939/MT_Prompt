# 一、图片存储方案（V1 本地）

你的情况：

- 图片量未来可能很多
- 图片尺寸可能很大（AI生成图通常几MB）
- GitHub不适合存图片
- 后期可能迁移 COS

所以：

## 不要把图片放数据库

这个一定确定。

错误：

```
SQLite

prompt表

image_blob
xxxxxxxxxxx
```

不要这样。

---

正确：

数据库只保存：

> 图片在哪里

例如：

```json
{
"id":101,
"type":"cover",
"path":"assets/images/2026/08/prompt001.jpg"
}
```

# 四、为未来COS预留一个抽象层

这个非常重要。

不要让代码里面到处写：

```javascript
读取本地文件
```

否则以后换COS很痛苦。

应该设计：

Storage Service。

例如：

```
storageService

       |
       |

----------------

LocalStorage

COSStorage

```

---

现在：

```
StorageService

↓

LocalStorage

↓

电脑硬盘

```

以后：

```
StorageService

↓

COSStorage

↓

腾讯COS

```

---

对于 Codex 来说，这个要求很容易实现。
