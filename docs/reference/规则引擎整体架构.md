# 四、规则结构我建议改成：

不是：

```
行业规则
```

而是：

## Prompt Skill（提示词技能）

这个更适合你的产品。

例如：

```
Prompt Skills

├── 参考图锁定

├── 商业摄影

├── 室内设计

├── 产品摄影

├── 人物一致性

├── 镜头语言

├── 视频运镜

```

---

为什么？

因为你实际积累的是：

“技巧”。

例如你的：

> LOCKED FROM REFERENCE IMAGE

它不是行业规则。

它是一种：

Reference Lock Skill。
